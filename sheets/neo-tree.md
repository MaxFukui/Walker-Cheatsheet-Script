# Neo-tree - File Explorer for Neovim
Toggle file explorer | <leader>e or :Neotree toggle
Open file explorer | :Neotree
Close file explorer | :Neotree close
Focus file explorer | :Neotree focus
Show current file | :Neotree reveal
Open file in split | s
Open file in vertical split | v
Open file in new tab | t
Rename file | r
Delete file | d
Add new file | a
Add new directory | A
Copy file | c
Cut file | x
Paste file | p
Refresh tree | R
Toggle hidden files | H
Toggle git ignored files | I
Show file preview | P
Copy file path | Y
Copy relative path | y
Search in tree | /
Filter nodes | f
Clear filter | <Esc>

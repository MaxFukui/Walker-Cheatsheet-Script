# Firefox - Browser Shortcuts

~ Shortcuts are listed as macOS / Linux

## Cache & Site Reset
~ For stubborn old app versions: hard reload first; if still stale, clear site data via padlock or unregister its Service Worker
~ Shift + click the Reload button also bypasses cache for the current page
Hard reload (bypass cache) | Cmd+Shift+R / Ctrl+Shift+R (or Ctrl+F5)
Clear site cookies & data | Click padlock in URL bar -> Clear cookies and site data
Clear recent history / cache | Cmd+Shift+Delete / Ctrl+Shift+Delete
Forget all data for a site | Cmd+Shift+H -> right-click site -> Forget About This Site
Disable cache (DevTools) | Cmd+Option+E / Ctrl+Shift+E -> check Disable Cache
Storage Inspector (site data) | Shift+F9
Unregister service workers | about:debugging#/runtime/this-firefox
Inspect service workers | about:serviceworkers
Manage site data settings | about:preferences#privacy

## DevTools
Open DevTools | Cmd+Option+I / Ctrl+Shift+I (or F12)
Web Console | Cmd+Option+K / Ctrl+Shift+K
Network Monitor | Cmd+Option+E / Ctrl+Shift+E
Responsive Design Mode | Cmd+Option+M / Ctrl+Shift+M
View page source | Cmd+U / Ctrl+U
Page info | Cmd+I / Ctrl+I

## Tabs & Windows
New tab | Cmd+T / Ctrl+T
Close tab | Cmd+W / Ctrl+W
Reopen closed tab | Cmd+Shift+T / Ctrl+Shift+T
New window | Cmd+N / Ctrl+N
New private window | Cmd+Shift+P / Ctrl+Shift+P
Reopen closed window | Cmd+Shift+N / Ctrl+Shift+N
Next / previous tab | Ctrl+Tab / Ctrl+Shift+Tab
Jump to tab 1-8 | Cmd+1..8 / Alt+1..8
Jump to last tab | Cmd+9 / Alt+9
Mute / unmute tab | Ctrl+M

## Navigation & Search
Reload page | Cmd+R / Ctrl+R (or F5)
Focus address bar | Cmd+L / Ctrl+L
Find in page | Cmd+F / Ctrl+F
Find next / previous | Cmd+G / Cmd+Shift+G (Linux: Ctrl)
Back / forward | Cmd+[ / Cmd+] (Linux: Alt+Left / Alt+Right)
Zoom in / out / reset | Cmd++ / Cmd+- / Cmd+0 (Linux: Ctrl)
Toggle Reader View | Cmd+Option+R / Ctrl+Alt+R
History library | Cmd+Shift+H / Ctrl+Shift+H
Bookmarks library | Cmd+Shift+O / Ctrl+Shift+O
Downloads | Cmd+J / Ctrl+Shift+Y
